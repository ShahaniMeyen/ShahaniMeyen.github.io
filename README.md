# Shahani Meyen Portfolio

A standalone React and Vite portfolio for Shahani Thasneem Meyen.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, normally `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Quality checks

```bash
npm run lint
npm run typecheck
```
